WIN KO HTUN — M&E TECHNICIAN ONLINE RESUME

Files:
- index.html: responsive online resume website
- assets/profile-photo.png: photo cropped from the existing resume PDF
- assets/resume.pdf: existing resume PDF for download

PREVIEW LOCALLY:
Open index.html in a web browser. Keep the assets folder next to index.html.

FREE HOSTING (GitHub Pages):
1. Create/sign in to a GitHub account.
2. Create a public repository, for example: win-ko-htun-portfolio
3. Upload index.html, README.txt, and the complete assets folder (including resume.pdf).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for the published URL shown in Settings > Pages.

IMPORTANT BEFORE PUBLISHING:
- Reference contact details were not present in readable form in the available resume, so the website clearly asks you to add verified details. Do not publish a referee's private contact information without permission.
- Review the phone number, email, LinkedIn link, experience dates, and resume PDF before making the site public.
- The website intentionally omits date of birth, passport number, marital status, and expected salary for privacy.
